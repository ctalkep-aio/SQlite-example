Бот для добавления заметок с помощтю SQlite
Telegram-бот для автоматизации записи клиентов в салон маникюра. Клиент выбирает услугу, отправляет номер телефона, а мастер получает уведомление в Telegram.

🚀 Возможности
✅ Добавление заметки с помощью команды /add;
✅ Вы можете посмотреть все свои заметки: /list;
✅ Удаление конкретной заметки: /del;
✅ Полностью удалить все заметки: /clear;
✅ Команды: /start, /add, /list, /del, /clear.
🛠 Технологии
Python 3.13+
Aiogram 3
SQLite
Telegram Bot API
